# Crona Development

Личный сайт независимого разработчика. React, TypeScript, Vite, Motion. RU/EN, адаптивная сетка, интро, контакты и облегчённый режим анимации.

## Локальная работа

Требуется Node.js 22.12+ (или совместимая версия, поддерживаемая Vite 7).

```sh
npm install
npm run dev
```

Сборка: `npm run build`. Предпросмотр сборки: `npm run preview`. Проверки: `npx vitest run`.

## Где менять содержимое

- `src/content.ts` — тексты обоих языков, названия услуг и этапы.
- `src/style.css` — палитра, оформление, мобильные правила и эффекты.
- `src/App.tsx` — компоненты страницы, контакты и бюджет.
- `public/crona.png` — исходная эмблема.
- `index.html` — исходные SEO-метаданные. При переключении языка описание и заголовок обновляются.

Валюта — USD. Бюджет $30–320 обновлён по запросу владельца; это фиксированный ориентир, не автоматическая конвертация. Иллюстрации в карточках услуг не представляют выполненные работы. Портфолио не отображается до появления настоящих проектов.

## Размещение

### GitHub Pages

Сайт: https://vlevickij683-a11y.github.io/crona-development/

В Settings → Pages выбран источник **GitHub Actions**. Workflow `.github/workflows/deploy.yml` при каждом push в `main` устанавливает зависимости, запускает тесты, собирает сайт и публикует `dist`. Адрес и базовый путь берутся из настроек Pages автоматически, поэтому изображения работают и в подпапке репозитория, и на собственном домене.

Для локальной проверки такой сборки задайте `VITE_BASE_PATH=/crona-development/` и `VITE_SITE_URL=https://vlevickij683-a11y.github.io/crona-development/` перед `npm run build`. Для обычной локальной разработки переменные не нужны.

### Другой статический хостинг

Выполнить `npm run build` и загрузить содержимое `dist`. При смене адреса задать публичный URL с завершающим `/` в `VITE_SITE_URL`; для размещения в подпапке также задать `VITE_BASE_PATH`. Эти переменные содержат только публичные адреса. Шрифт Manrope загружается из Google Fonts; при недоступности используется системный sans-serif.

Локальная копия проекта также настроена для ChatGPT Sites через `.openai/hosting.json`. Этот файл относится к отдельному хостингу и не требуется для GitHub Pages.

## Поведение

Язык сохраняется в localStorage. Интро показывается один раз за сессию, его можно пропустить. При `prefers-reduced-motion` интро и движения отключены. Контакты открывают Telegram и почтовый клиент. Аккаунты, форма заявки и серверная часть отсутствуют.

## Проверка версии

Сборка и TypeScript проверяются командой build. Автотесты проверяют смену языка, контакты и управление меню. Визуальную проверку на реальных размерах экранов нужно завершить при восстановлении соединения с браузером Codex.

Эффекты TechText, CRTWarp, ShapeGrid, HoldButton, Carousel и Crosshair взяты из React Bits (https://reactbits.dev), лицензия: src/bits/LICENSE.md. Изменены локализация и настройки под Crona. trace-logo.py создаёт SVG-контуры четырёх частей оригинальной эмблемы для анимации; PNG не изменяется.
